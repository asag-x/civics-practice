# Civics Practice

Ten sample questions from the official USCIS 2025 civics question bank. Flashcards, five- or ten-question quizzes, missed-question review, and progress saved on the device.

## Publish with GitHub Pages

1. Create a free public GitHub repository named civics-practice.
2. Extract this ZIP. Upload its contents to the repository's main branch so index.html is at the top level.
3. In Settings → Pages, choose Deploy from a branch, then main and /(root). Save.
4. When deployment finishes, select Visit site. Open the link in iPhone Safari. Tap Share → Add to Home Screen, enable Open as Web App if shown, then tap Add.
5. Open the installed app once while online so it can download its offline files.

For local desktop practice, open index.html. To test offline installation locally, serve the folder over localhost. After changing app assets, increment the version suffix in sw.js so returning devices download the new files.
